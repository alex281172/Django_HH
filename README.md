# Парсер вакансий hh.ru на Django

Веб-приложение: вы указываете профессию, город и сколько вакансий разобрать – оно собирает вакансии через API hh.ru и показывает, какие навыки, города и зарплаты встречаются чаще всего.

Дипломный проект курса «Python developer», Университет искусственного интеллекта, 2022.

**Демо:** https://alex281172.github.io/Django_HH/ – результат одного запроса, сохранённый в базе проекта.

## Что умеет

- **Сбор данных.** Запросы к API hh.ru постранично, по 20 вакансий. Навыки берутся из карточки каждой вакансии.
- **Аналитика.** Рейтинг навыков с долями, распределение вакансий по городам, средняя зарплата по городу (только вакансии с зарплатой в рублях).
- **Облака слов** навыков и городов (wordcloud, matplotlib).
- **Редактирование данных.** Списки навыков и городов на class-based views: просмотр, создание, правка, удаление. Админка Django.
- **Пользователи.** Своя модель пользователя, регистрация, вход, профиль, выпуск и обновление API-токена (в том числе через AJAX).
- **REST API** на Django REST Framework:
  - `/api/v0/cities/` и `/api/v0/cities_salary/` – читают все, меняет только администратор;
  - `/api/v0/skills/` – после входа по сессии, логину или токену.
- **Тесты.** 20 тестов на модели и представления (unittest, mixer).

## Стек

Python 3.10, Django 4.0, Django REST Framework, SQLite, requests, wordcloud, matplotlib, NumPy, Pillow, Bootstrap, jQuery.

## Запуск

```bash
git clone https://github.com/alex281172/Django_HH.git
cd Django_HH
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cd DjangoHH
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000 и войдите под созданным пользователем. Форма запроса – на главной странице.

Тесты: `python manage.py test`

### Настройки через переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DJANGO_SECRET_KEY` | секретный ключ | ключ только для локального запуска |
| `DJANGO_DEBUG` | `1` – режим отладки, `0` – выключен | `1` |
| `DJANGO_ALLOWED_HOSTS` | разрешённые хосты через запятую | `127.0.0.1,localhost` |
